BINHI is expanding into an all-in-one multimedia editor/creator, not being
rebuilt. Preserve every existing website workflow and do not modify
ORIGIN/TALA as part of studio work.

**Why:** The user explicitly asked for “tools for editing not just a website”
and a true all-in-one studio while preserving the already working product.

**How to apply:** Add bounded document-specific modules rather than expanding
SiteDocument into a universal canvas. Keep unfinished capabilities honest.

Private photo originals must not silently reuse the existing website media
destination. Website media has publicly reachable URLs.

**Why:** The first milestone deliberately avoids production schema changes;
local processing is safer than storing private originals as public assets.

**How to apply:** Keep originals local until a private cloud project/asset
contract is approved. Reuse existing website storage only for explicitly
confirmed exported copies, with a clear public-media warning.
